# Есть дефект или нет

Минимальный Python-проект для кейса «Компьютерное зрение»: принимает путь к
изображению и печатает `OK` (норма) или `DEFECT` (брак). Работает локально,
без обучения модели, GPU и API-ключей.

**Состав:** `detect.py` — вся логика; `requirements.txt` — зависимость;
`ok.png` и `defect.png` — две демонстрационные картинки; `README.md` — инструкция.

## Установка и запуск

Нужен Python 3.10+; проверено на Python 3.12.14 и Pillow 12.3.0.
Распакуйте архив и откройте терминал в папке `defect-checker`.

```bash
python -m pip install -r requirements.txt
python detect.py ok.png
# OK
python detect.py defect.png
# DEFECT
```

Для своей картинки и другого порога:

```bash
python detect.py "path/to/photo.jpg" --threshold 0.20 --details
```

На Windows вместо `python` можно использовать `py`, на Linux/macOS — `python3`.
При желании перед установкой создайте окружение: `python -m venv .venv`;
активируйте `.venv\Scripts\Activate.ps1` в PowerShell или
`source .venv/bin/activate` в Linux/macOS.

## Как это работает

Pillow открывает изображение и переводит его в RGB; прозрачность накладывается
на белый фон. Пиксель считается красным, если одновременно `R >= 150`,
`R - G >= 50` и `R - B >= 50` (каналы от 0 до 255). Скрипт делит количество
таких пикселей на общее число пикселей. Если доля **не меньше 10%**, выводится
`DEFECT`, иначе `OK`. Порог задаётся через `--threshold` в диапазоне `(0, 1]`.

В stdout всегда только результат; `--details` добавляет долю красного и порог
в stderr. Код завершения: `0` для обоих результатов, `1` при ошибке чтения,
`2` при неверных аргументах. Подходят, например, PNG, JPEG, WebP и BMP;
у многостраничных или анимированных изображений анализируется первый кадр.

## Что получилось

| Картинка | Содержимое | Доля красного | Результат |
| --- | --- | --- | --- |
| `ok.png` | Зелёный квадрат 256 × 256 | 0% | `OK` |
| `defect.png` | Красный квадрат 256 × 256 | 100% | `DEFECT` |

Это демонстрация простого цветового правила из задания: красный предмет тоже
будет признан браком, а дефект другого цвета может остаться незамеченным.
Результаты на двух квадратах не оценивают качество на реальных изделиях.

Документация: [Pillow 12.3.0](https://pypi.org/project/pillow/12.3.0/),
[операции над каналами](https://pillow.readthedocs.io/en/stable/reference/ImageChops.html).
